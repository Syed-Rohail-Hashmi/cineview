# CineView

A movie explorer website made with HTML, CSS and JavaScript. You can search for movies, browse Popular and Top Rated lists, filter by genre, and watch trailers.

## Built With

- HTML
- CSS
- JavaScript
- TMDB API

## How to Run

1. Download this project.
2. Make a free account on themoviedb.org and get your own API key.
3. In the project folder, create a new file named `config.js`.
4. Write this one line inside it: `const API_KEY = 'YOUR_API_KEY_HERE';`
5. Replace `YOUR_API_KEY_HERE` with your own key and save the file.
6. Double-click `index.html`.

The `config.js` file is not uploaded to GitHub on purpose, so the key stays private.

This product uses the TMDB API but is not endorsed or certified by TMDB.
